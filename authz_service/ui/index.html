Getting started

  1. Create a tenant and an application.
  2. Define permissions (resource.action) and group them into roles.
  3. Pre-provision users (or let them auto-provision on first login) and grant memberships.
  4. Optionally register agents — they never get more than the acting user.
  5. Check the result in the decision probe and watch denies in the audit log.
